🏆 Mi Aplicación Web: 
Gestión de Equipos & Blog
Esta plataforma es una solución integral desarrollada con Python y Django que combina la administración técnica de equipos deportivos con un sistema de blog dinámico y perfiles de usuario personalizados.

🚀 Características Principales⚽ 
Gestión de Equipos (CRUD)
Administración completa de entidades deportivas:Creación y Visualización:
Listado detallado de equipos.
Edición Dinámica:
Actualización de nombres, años de fundación y estadísticas.Multimedia: Soporte para la carga y visualización de escudos de los equipos.✍️ Sistema de Blog ProfesionalUn espacio para compartir contenido con estilo:
Editor Enriquecido: Integración con CKEditor para posts con formato profesional.Organización: Títulos, subtítulos y fechas de publicación automatizadas.👤 Usuarios y PerfilesSeguridad: Sistema robusto de registro, login y logout.Personalización:
Perfiles individuales con biografía, fecha de nacimiento, avatar (imagen de perfil) y selección de equipo favorito.

📝⚙️ Instalación y Ejecución Local
Si querés probar el proyecto en tu máquina, seguí estos pasos:

1. Clonar el repositorio

Abrí tu terminal (Git Bash, PowerShell o CMD) y ejecutá:
Bash git clone https://github.com/thyagomaderna-star/TuPrimeraPagina-Maderna.git
cd TuPrimeraPagina-Maderna
code .
2. Configurar el entorno virtualEs necesario tener Pipenv instalado para gestionar las dependencias:Bash# Instalar pipenv (si no lo tenés)
pip install pipenv

# Instalar dependencias del proyecto
pipenv install
3. Lanzar la aplicaciónActivá el entorno y levantá el servidor de desarrollo:Bash# Activar el entorno virtual
pipenv shell

# Iniciar servidor
python manage.py runserver
📍 Accedé desde tu navegador en: http://127.0.0.1:8000/
