Clonar el repositorioAbrí tu terminal (Git Bash, PowerShell o CMD) y ejecutá:Bashgit clone https://github.com/thyagomaderna-star/TuPrimeraPagina-Maderna.git
cd TuPrimeraPagina-Maderna
code .
2. Configurar el entorno virtualEs necesario tener Pipenv instalado para gestionar las dependencias:Bash# Instalar pipenv (si no lo tenés)
pip install pipenv

# Instalar dependencias del proyecto
pipenv install
3. Lanzar la aplicaciónActivá el entorno y levantá el servidor de desarrollo:Bash# Activar el entorno virtual
pipenv shell

# Iniciar servidor
python manage.py runserver
